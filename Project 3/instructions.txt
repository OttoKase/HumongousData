nb! in order for the http sensor to work I had to create a debezium_connect in airflow. 
Admin → Connections → + (Add a new record)
Fill in exactly:

Connection Id: debezium_connect
Connection Type: HTTP
Host: connect
Port: 8083
Schema: http

Leave everything else blank, hit Save, then re-trigger the DAG.
